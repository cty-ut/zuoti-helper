# 做题助手

Windows 学习辅助小工具：选中题目文字按 F8，或用 Alt + 滚轮框选截图，即可得到答案和简要解析。答案同时显示在电脑小窗和同一 WiFi 下的手机 / 平板网页上（支持 Markdown、代码高亮和数学公式）。

## 下载与使用

1. 到 [Releases](../../releases) 下载最新的 `zuoti-helper-x.y.z.zip`，完整解压到一个文件夹。
2. 用记事本打开 `config.json`，在 `"api_key"` 后填入你拿到的授权码并保存。
3. 双击 `做题助手.exe` 运行。

详细说明见压缩包里的 `使用说明.txt`。

## 快捷键

| 按键 | 作用 |
|---|---|
| F8 | 读取选中的文字并答题 |
| Alt + 滚轮 | 第一下标记点 1，第二下标记点 2，截取两点之间的区域 |
| 右 Shift | 切换档位：1 快速 / 2 标准 / 3 最强 |
| 右 Alt | 切换模式：选择题 / 问答题 / Python / Java / C++ |
| ↑ / ↓ | 滚动手机上的网页 |

## 隐私

- 不读写剪贴板，截图只在内存中处理，不保存到硬盘。
- 题目经中转服务器转发给 DeepSeek，服务器不记录题目和答案内容。

## 系统要求

Windows 10 / 11（64 位）。杀毒软件或 SmartScreen 可能因为程序使用了全局快捷键且未签名而提示风险，点"更多信息"→"仍要运行"即可。

> 本工具仅用于学习和复习，请勿用于任何考试。
